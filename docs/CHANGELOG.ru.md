## 📅 Версия 1.4.0 (Текущая)

### ⚡ Zero-Latency Rolling Commit и Tail Finalization
- Устранен тяжелый повторный прогон всего накопленного аудиофайла при остановке записи.
- Текст накапливается порциями в `committed_text` во время естественных пауз речи (800 мс) или по таймеру (12 с).
- Кнопка «Стоп» декодирует только незафиксированный хвост с нахлестом 300–400 мс и контекстным промптом, сводя задержку финализации к нулю.

### 🛡️ Жесткий акустический гейт (Acoustic Guard)
- Добавлена проверка полезной энергии звука и длительности перед вызовом Whisper в воркере и при остановке.
- Отрезки звука короче 350 мс или с RMS < 0.003 мгновенно прерываются без обращения к GPU (0 токенов, исключение галлюцинаций в тишине).

### 🚫 Черный список титров YouTube и закрывающих слов
- В `is_hallucination` добавлены регулярные выражения для титров и метаданных переводчиков («субтитры создавал», «дима торзок», «dimatorzok», «amara.org», «редактор субтитров»).
- Закрывающие фразы («Спасибо», «Благодарю», «Конец») отсекаются ТОЛЬКО если весь сегмент состоит из них, на 100% сохраняя реальные предложения.

### 🌊 Непрерывный гибридный стриминг
- **Приоритет Groq**: при наличии ключа воркер каждые 500–600 мс (первый чанк через 450 мс) выдает растущий черновик с задержкой < 200 мс.
- **Локальный фолбек**: в офлайн-режиме Whisper декодирует скользящее 3-секундное окно каждые 800 мс без блокировки по паузе.
- **Безопасная склейка**: `safe_space_concatenate` соединяет базу и текущий драфт, предотвращая стирание текста с экрана.
- **Динамический UI-сплит**: `HeaderBar` отображает стабильные слова белым цветом, а последние 1–2 слова — серым курсивом с пульсирующей красной точкой.

### 🔄 Сворачивание циклических зацикливаний и повторов (N-gram Loop Collapse)
- Реализован алгоритм `collapse_ngram_repetitions` в `utils.rs`, распознающий повторы цепочек слов (от 1 до 8 токенов).
- Устраняет авторегрессионные зацикливания Whisper (например, многократные *«в принципе, в принципе...»*), сворачивая их строго в одно вхождение с сохранением закрывающей пунктуации.

### 🔒 Регламент Frozen Pipeline Rule
- В `AGENTS.md` и `docs/TRANSCRIPTION_PIPELINE.md` закреплено правило №7 о неизменности аудиозахвата, VAD, параметров Whisper (`no_speech=0.68`, `temp=0.0`), дедупликации и промптов без явной команды `редактируем [компонент]`.

## 📅 Версия 1.3.2

### 🛡️ Верификация плотности стриминга и детектор зависаний
- В функцию `stop_recording` внедрен анализатор плотности речи `word_count / duration`.
- Если запись длилась более 5 секунд, а плотность слов указывает на замерзание стриминга или лимит запросов, система автоматически выполняет чистовую батч-транскрипцию всего записанного WAV-файла.

### ⚡ Универсальный Engine-Agnostic Fallback-пайплайн
- Выстроена единая цепочка подстраховки для всех поддерживаемых провайдеров (GigaChat, Groq, Whisper, Gemini, Deepgram, DeepSeek, Qwen).
- При сетевых сбоях или ошибках квот ИИ-форматирования исходный распознанный текст гарантированно сохраняется и вставляется в приложение без потерь.

### 🔄 Авто-повтор при Rate Limit (429/503) и лимит генерации
- Добавлена логика автоматического повтора с паузой 1.2 секунды при получении ошибок перегрузки (`429`, `503`) от серверов LLM.
- Лимит генерации увеличен до `max_tokens: 4096`, обеспечивая работу с непрерывными монологами до 20–25 минут.

### ❓ Расстановка знаков вопроса и оптимизация частоты опроса
- В системный промпт `REFINEMENT_SYSTEM_PROMPT` добавлены строгие правила и эталонные примеры для точного распознавания вопросительных интонаций и обязательной постановки знака `?`.
- Интервал фонового стриминга оптимизирован до 650 мс с защитой от 429 ошибок.

#### 7. **Оптимизация скорости локального Whisper** ✅

**Проблема:** Локальная транскрибация Whisper занимала ~57 секунд на M1 MacBook Air (47с на инициализацию Metal GPU + 10с инференс).

**Причина:** `WhisperContext` кэшировался, но `WhisperState` пересоздавался при каждом вызове. Каждое новое состояние запускало полную reinit Metal backend — компиляцию ~20 GPU шейдерных пайплайнов (~47 секунд).

**Решение:**
- ✅ **Кэширование WhisperState**: Теперь кэшируются И контекст, И состояние в структуре `WhisperModel` — Metal компилируется один раз, используется для всех вызовов
- ✅ **Предзагрузка модели**: Модель Whisper загружается в фоне при старте приложения — первый запрос не платит за cold-start
- ✅ **Снятие лимита потоков**: Убрано `.min(4)` — теперь используются все доступные ядра CPU (8 на M1)
- ✅ **Metal pre-warm**: Мини-инференс на тишине при загрузке модели компилирует все GPU-шейдеры заранее

**Результат:** Локальная транскрибация ускорена с ~57с до ~10с на фразу (**~6x быстрее**).

### 🎯 Сценарии использования

#### Сценарий 1: Быстрое копирование фрагмента
1. Нажмите хоткей → скажите текст
2. Выделите фрагмент мышью или клавиатурой
3. Текст **автоматически копируется**
4. Появляется **"✓ Скопировано!"** на 0.6 секунды
5. Продолжайте работу

#### Сценарий 2: Запись с авто-вставкой
1. Включите "Авто-вставка" в настройках
2. Нажмите хоткей → скажите текст
3. Окно **автоматически поверх всех окон**
4. После обработки → **автоматическая вставка**
5. Окно **скрывается**

#### Сценарий 3: Чистое распознавание (без AI)
1. **Отключите форматирование** (кнопка Zap)
2. Скажите текст
3. Получите **чистый текст без изменений**
4. Никаких переводов или добавок

### 📝 Известные ограничения

1. **Выделение текста** работает только в режиме `result`
2. **Авто-копирование** срабатывает при выделении > 0 символов
3. **AlwaysOnTop** сбрасывается после вставки текста
4. **Форматирование** требует API ключ (Gemini/Qwen/DeepSeek)
