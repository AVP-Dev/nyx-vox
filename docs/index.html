How NYX Vox Works

Как это работает

From spoken words to text in your active window.

От произнесённой фразы до текста в активном приложении.

01

Capture & Smart VAD

Захват звука и VAD

High-fidelity 16 kHz audio capture with calibrated Noise Gate and smart speech activity detection (VAD). Auto-stops on natural silence.

Захват аудио 16 кГц с откалиброванным шумоподавлением и умным определением пауз речи (VAD). Автоматическая остановка по тишине.

02

Speech recognition

Распознавание речи

Choose local Whisper or send audio to the cloud provider you select in Settings.

Используйте локальный Whisper или отправляйте аудио облачному провайдеру, выбранному в настройках.

03

Optional AI formatting

ИИ-форматирование по желанию

When enabled, the formatter sends the transcript to the selected AI provider to adjust punctuation, capitalization and paragraphs.

Если включить форматтер, текст отправляется выбранному ИИ-провайдеру для расстановки знаков препинания, правки регистра и разбивки на абзацы.

04

Native HID Auto-Paste

Нативная Автовставка

Direct synthetic input injection via macOS Accessibility API and Windows Enigo. Text instantly appears in VS Code, Telegram, Slack, Word, or your browser without manual pasting.

Прямая эмуляция ввода через Accessibility API (macOS) и Enigo (Windows). Текст мгновенно печатается в VS Code, Telegram, Slack или браузере без нажатия Cmd+V / Ctrl+V.

How to Update NYX Vox

Как обновить NYX Vox

Starting with v1.6.2, NYX Vox updates natively inside the app: it checks releases automatically, shows an indicator in the tray, and downloads, verifies, installs, and relaunches in one click.

Начиная с v1.6.2, NYX Vox обновляется нативно внутри приложения: сам проверяет релизы, показывает индикатор в трее и скачивает, проверяет подпись, устанавливает и перезапускает всё в один клик.

In-App Auto-Updater Автообновление в приложении Native · macOS & Windows Нативно · macOS и Windows

Click Update Available (or Check for Updates...) in the system tray to open the compact update window, review release notes, and install with live progress. All models, encrypted API keys, and settings stay intact.

Нажмите «Доступно обновление» (или «Проверить обновления...») в трее — откроется компактное окно с описанием изменений и прогрессом установки. Модели, зашифрованные ключи и настройки сохраняются.

macOS note: since builds are distributed without an Apple Developer ID, macOS may ask you to re-toggle Accessibility permission after an auto-update.

Примечание для macOS: так как сборки выходят без платной подписи Apple Developer ID, после автообновления может потребоваться перевключить «Универсальный доступ» (Accessibility).

Homebrew macOS · Recommended
brew update && brew upgrade --cask AVP-Dev/apps/nyx-vox

If installed via Homebrew, upgrade to the latest release with a single terminal command. Preserves your settings and speech models.

Если вы устанавливали через Homebrew, обновитесь до актуального релиза одной командой. Настройки и модели сохраняются.

curl script macOS
curl -fsSL https://nyx-vox.avpdev.com/install.sh | /bin/bash

Re-run the automated installer. It verifies the latest SHA-256 DMG, replaces the app in Applications, and preserves settings.

Повторный запуск скрипта проверяет контрольную сумму нового DMG, заменяет приложение и сохраняет ваши настройки.

Manual DMG macOS · Manual
xattr -dr com.apple.quarantine "/Applications/NYX Vox.app"

Download the newest DMG and replace in /Applications. Run the command above if macOS gatekeeper blocks launch.

Скачайте свежий DMG и замените в «Программах». Выполните команду выше, если macOS блокирует запуск приложения.

Tip: Toggle accessibility permission if auto-paste stops after replacement.

Совет: Перевключите Универсальный доступ, если автовставка не сработала после замены.

Установка на macOS

Apple Silicon · Homebrew

Apple Silicon · Homebrew

Apple Silicon · curl

Apple Silicon · curl

To start dictating, open NYX Vox, grant microphone access and enable Accessibility on macOS for auto-paste. Focus an input field and press Option + Space on macOS or Ctrl + Space on Windows.

Чтобы начать диктовку, откройте NYX Vox, разрешите доступ к микрофону и включите «Универсальный доступ» на macOS для автовставки. Поставьте курсор в поле ввода и нажмите Option + Space на macOS или Ctrl + Space на Windows.

If macOS blocks an app installed manually from the DMG

Если macOS блокирует приложение после ручной установки из DMG

xattr -dr com.apple.quarantine "/Applications/NYX Vox.app"

Windows 10 / 11 Installation Note

Установка на Windows 10 / 11

When launching the unsigned installer, Windows SmartScreen may show “Windows protected your PC”. Click More info → Run anyway. Ensure microphone access is permitted for desktop apps in Windows Settings → Privacy & Security → Microphone.

При первом запуске неподписанного установщика фильтр SmartScreen может показать предупреждение. Нажмите «Подробнее» → «Выполнить в любом случае». Убедитесь, что доступ к микрофону разрешён в Параметрах Windows → Конфиденциальность и безопасность → Микрофон.
